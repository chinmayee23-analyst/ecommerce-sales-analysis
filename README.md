# ecommerce-sales-analysis
Beginner data analytics project using Python and Pandas to explore e-commerce sales data.

## Project Overview
This project analyses historical online retail transactions
to understand repeat purchasing behaviour and identify
opportunities to improve customer retention.

## Business Question
How many customers make repeat purchases, and what
patterns can help the business encourage customers to return?

## Dataset
Source: UCI Machine Learning Repository — Online Retail
https://archive.ics.uci.edu/dataset/352/online+retail

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Checked missing values and duplicate records
- Cleaned transaction data
- Analysed unique and repeat customers
- Examined monthly invoice trends
- Compared customer spending patterns
